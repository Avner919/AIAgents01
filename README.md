## Сервис `ЕСПП`

Сервис `ЕСПП` предназначен для приема/выплаты почтовых переводов, а также для взаимодействия с ГП ЕСПП.

## Репозитории сервиса `ЕСПП`

Сервис `ЕСПП` состоит из двух gitlab-репозиториев:
- **backend**: https://gitlab.tools.russianpost.ru/eas-business/espp/espp-backend
- **frontend**: https://gitlab.tools.russianpost.ru/eas-business/espp/espp-frontend

## Взаимодействие с другими сервисами

Сервис `ЕСПП` взаимодействует через шину данных `NATS` с сервисами:
- [Russian.Post.MARS.Discovery](https://confluence.tools.russianpost.ru/pages/viewpage.action?pageId=187791899)
- [Russian.Post.MARS.WatchDog](https://confluence.tools.russianpost.ru/pages/viewpage.action?pageId=187791829)
- [Russian.Post.EAS4.RefBooks](https://confluence.tools.russianpost.ru/pages/viewpage.action?pageId=288079874)
- [Russian.Post.EAS4.Cart](https://confluence.tools.russianpost.ru/pages/viewpage.action?pageId=302750086)

## Функции сервиса

Сервис `ЕСПП` предоставляет следующие возможности:
- **`прием переводов`**
  - прием единичного перевода
  - прием партии переводов (от одного отправителя)
  - партионный прием переводов (электронный файл)
- **`выплата переводов`**
  - выплата единичного перевода
  - выплата партии переводов (одному получателю)
- **`просмотр переводов`**
  - просмотр таблицы переводов
  - просмотр таблицы операций по переводам
  - детализация данных по выбранному переводу
  - детализация данных операции по выбранному переводу
  - формирование печатных бланков по приему/выплате
- **`запросы по переводам`** (дополнительные операции над переводами)
  - запрос состояния (выбранных) переводов
  - запрос возврата (выбранных) переводов
  - запрос возврата (выбранных) переводов на пункт приема
  - запрос депонирования (выбранных) переводов
  - запрос досыла (выбранных) переводов
  - запрос переадресации (выбранных) переводов
  - регистрация результатов доставки (выбранных) переводов
  - регистрация переводов в доставку по заявлению
- **`административные функции сервиса`** (функции доступные только начальнику ОПС)
  - конфигурация сервиса
  - инсталляция пункта обмена
  - восстановление пункта обмена
  - обмен с ГП (обмен выполняется по планировщику и принудительно по запросу)

## Ограничения

Сервис `ЕСПП` имеет ряд ограничений:
- сервис работает на ПК под управлением ОС Windows
- сервис взаимодействует с `Microsoft SQL Server 2012`
- сервис взаимодействует с утилитой обмена `ElpClient` (`m_exchange`)
- сервис взаимодействует c другими сервисами по локальной шине данных ОПС

## Логирование

Сервис `ЕСПП` логирует:
- все сообщения, прочитанные из шины NATS/NATS Streaming
- все сообщения, отправленные через шину NATS/NATS Streaming
- исключения, возникшие в процессе работы сервиса
- дополнительные информативные сообщения

Все логи хранятся в папке **C:\\ProgramData\\Russian.Post.EAS4\\Espp**.
