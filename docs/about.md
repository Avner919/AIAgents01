# О проекте AIAgents01

Репозиторий: [Avner919/AIAgents01](https://github.com/Avner919/AIAgents01).

## Краткое описание

Проект содержит консольную утилиту `Exchange` для управления файловым обменом с ГП через внешний клиент `m_exchng.exe` (ElpClient). Утилита запускает клиент, координирует его работу через именованные события Windows, ожидает завершения обмена с заданным таймаутом и записывает диагностические сообщения в лог. Результат выполнения возвращается кодом завершения процесса.

Настройки загружаются из `embeddedsettings.json`, затем `appsettings.json` и переменных окружения; последующие источники переопределяют предыдущие. Для реального обмена нужны Windows, установленный внешний клиент и настроенные каталоги входящих и исходящих файлов.

## Стек

- **C# / .NET 8** — консольное приложение `Exchange/Exchange.csproj` с целевой платформой `net8.0`.
- **Windows API через .NET** — управление процессами и синхронизация через `EventWaitHandle`.
- **Microsoft.Extensions.Configuration** — загрузка JSON-конфигурации, переменных окружения и привязка настроек к моделям.
- **NLog 6.0.4 / NLog.Web.AspNetCore 6.0.4** — журналирование с настройками в `Exchange/exchangeNlog.config`.
- **xUnit 2.9.3 / Microsoft.NET.Test.Sdk 17.14.1 / xunit.runner.visualstudio 3.1.5** — тестовый проект `Tests/Exchange.Tests.csproj` и запуск через `dotnet test`.
- **.NET CLI / NuGet** — сборка, восстановление зависимостей и тестирование; решение `AIPractice1.slnx` требует SDK с поддержкой формата `.slnx`.

Существующий end-to-end тест `Tests/ProgramEndToEndTests.cs` проверяет ошибку запуска при некорректной конфигурации в изолированном временном каталоге, не затрагивая реальные процессы клиента обмена. Команда запуска всех тестов: `dotnet test AIPractice1.slnx` из корня репозитория.
